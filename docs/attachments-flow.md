# Flux des pièces jointes

## Endpoints

```
POST /messaging/api/v1/attachments/upload         - Upload direct
POST /messaging/api/v1/messages/:id/attachments   - Lier à un message
GET  /messaging/api/v1/attachments/:id             - Métadonnées
GET  /messaging/api/v1/attachments/:id/download    - Télécharger
DELETE /messaging/api/v1/attachments/:id           - Supprimer
GET  /messaging/api/v1/messages/:id/attachments    - Lister par message
```
